# Python RAG 私有知识库技能

## 功能说明

基于本地 ChromaDB 向量数据库的私有知识库检索与管理工具，支持文档上传入库、语义检索问答，所有数据本地存储，不上传云端。

## 适用场景

- 用户上传文档，要求加入私有知识库
- 查询内部产品说明、业务规则、文档内容
- 需要基于本地私有文档回答问题

## 使用方式

用户提出相关问题或上传文件时自动调用。

## 注意事项

- 本技能依赖本地 ChromaDB 服务，请确保 ChromaDB 已启动
- 文档入库后可通过自然语言查询检索
- 所有数据存储在本地，不上传云端
