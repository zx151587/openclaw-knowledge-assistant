# Daily Knowledge Brief Prompt

请严格遵循以下指令检索个人知识库中**昨日（UTC+8 时区）**新增的文档和网页内容，生成一份中文知识简报。

## 输出格式要求（必须严格按此结构）：
1. **📊 新增数量**：统计文档和网页分别新增了多少条。
2. **📂 来源类型**：区分来自“文档上传”还是“网页采集”。
3. **🏷️ 主要标签**：列出出现频率最高的 3-5 个标签。
4. **📝 每条摘要**：简洁列出新增知识的标题和一句话摘要。
5. **❓ 推荐复习问题**：针对今日新增内容，提出 2 个问答题。

## 特殊规则：
- 如果昨日无新增内容，请直接回复：“📭 昨日暂无新增知识，请记得保持输入哦。”
- 检索范围：ChromaDB 中 `createdAt` 字段为昨日 00:00:00 至 23:59:59 的记录。
- 不要编造数据，严格基于知识库返回的内容生成。
